# twilio-app

A simple voice bot service (Twilio) deployed and runnable with Docker Compose.

Deployed (live) URL
- https://twilio-app-git-trillio-twillio.2.rahtiapp.fi/voice

Quick start (run locally)
1. Clone the repository
```bash
git clone https://github.com/klingaje/twilio-app.git
cd twillio-app
```

2. Start with Docker Compose
```bash
docker compose up --build
```

3. Stop and remove containers
```bash
docker compose down
```
